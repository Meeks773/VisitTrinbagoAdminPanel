---
name: Spreadsheet review policy
description: Why TTL spreadsheet imports remain drafts and uncertain data must be preserved for review.
---

Import all genuine place records as drafts, without inventing missing descriptions, prices, coordinates, or images. Offers are not places. Keep uncertain duplicate matches for review, particularly same-named businesses with different branches.

**Why:** The user chose to review all place rows, not only verified entries. The supplied workbook combines researched content, incomplete submissions, repeated verified versions, and staff follow-up notes. A completed-looking record must not be mistaken for a verified one.

**How to apply:** Future import improvements should preserve source context privately, retain verified versions over matching unverified copies, and require explicit approval before public visibility. Do not convert staff notes into public descriptions or automatically fill missing facts using AI.
